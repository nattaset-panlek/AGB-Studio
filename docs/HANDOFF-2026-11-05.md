## เรื่องแรกที่ต้องทำ: Smart App Control

ค่า `HKLM\SYSTEM\CurrentControlSet\Control\CI\Policy\VerifiedAndReputablePolicyState` เป็น `1` (เปิดบังคับใช้) ผลที่เห็น:

```
Could not load file or assembly '...\AgbStudio.Scripting.dll'.
An Application Control policy has blocked this file. (0x800711C7)
```

- ไฟล์ที่โดนบล็อกเปลี่ยนไปตามการ build: เคยเจอ `AgbStudio.Analyzers.dll`, `AgbStudio.Scripting.dll` และ `agb.dll`
- ตัว editor ที่ `editor/AgbStudio.Editor/bin/Release/net10.0` ปิดตัวทันทีตอนเปิดหน้าจอ (exit code `0xE0434352`) แต่ `--mcp` ยังตอบ `initialize` ได้ จนกว่าจะเรียก `agb_build_rom`
- **การตัดสินใจเป็นของเจ้าของเครื่อง ห้ามแก้การตั้งค่าความปลอดภัยให้เอง** ถ้าปิด Smart App Control แล้ว จะเปิดกลับได้ก็ต่อเมื่อติดตั้ง Windows ใหม่หรือรีเซ็ตเครื่อง
- ถามเจ้าของก่อนว่าปิดแล้วหรือยัง ถ้ายังไม่ปิด การ build ใหม่อาจผ่านหรือไม่ผ่านก็ได้ ไม่มีอะไรรับประกัน
