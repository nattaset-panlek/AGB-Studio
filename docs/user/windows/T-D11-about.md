# About

Figma: T-D11 · Dialog

> ข้อมูลเวอร์ชันและเครดิตของเครื่องมือที่ใช้

Shows the version of AGB Studio and credits the tools it is built on.

## Opens from

- Help › About AGB Studio

## What is on it

- **Title bar**: "About AGB Studio", with a close button.
- **App icon and name**: the AGB Studio icon and wordmark.
- **Version line**: the version number and the build date, for example "Version 1.0.0 · 2026-10-31". Quote this
  line when you report a bug.
- **Credits**: AGB Studio is built on devkitPro (devkitARM, libtonc, maxmod) and the mGBA emulator core. Scripts are
  C#, turned into C++ with Roslyn.
- **Licenses**: opens the third-party notices (`THIRD_PARTY.md`). If that file is missing from the install, a message
  says so.
- **Website**: opens the AGB Studio website. The button is greyed out when no website address is set for this
  install.
- **Close**: closes the dialog.
