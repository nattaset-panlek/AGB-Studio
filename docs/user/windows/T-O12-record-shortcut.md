# Record Shortcut

Figma: T-O12 · Popover

> กดปุ่มที่ต้องการเพื่อตั้งปุ่มลัดใหม่ ถ้าชนกับคำสั่งอื่นจะเตือนและให้เลือกว่าจะแทนที่หรือไม่

Press the keys you want as the new shortcut. If they are already used by another command, a warning appears and you
choose whether to replace it.

## Opens from

- Preferences › Shortcuts › pencil button on a command row

## What is on it

- **Title**: "New shortcut · " and the command name, for example "New shortcut · Toggle grid", with a close button.
- **Key box**: shows the command's current keys at first. Press a key, with Ctrl, Shift or Alt if you like, and the box
  shows the new keys. Pressing only Ctrl, Shift, Alt or Windows does nothing; press another key with them.
- **Conflict line**: appears when the keys are taken, for example: Ctrl+G is used by “Go to line”.
- **Cancel** (or Esc, or the close button): closes without changing anything.
- **Replace**: greyed out until you press keys. It gives the keys to this command and removes them from the command
  that used them. The change is kept when you press Save in Preferences.
