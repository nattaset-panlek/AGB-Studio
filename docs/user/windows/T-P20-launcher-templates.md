# Launcher · Templates

Figma: T-P20 · Page

No caption in Figma.

The Templates tab of the Launcher: browse the genre templates, read what each one includes, and start a new project
from one.

## Opens from

- Launcher › Templates tab
- All templates, on the Launcher home (Projects tab)

## What is on it

The top bar (Open…, New Project) and the sidebar (Projects, Templates, Learn, Settings) are the same as on the
[Launcher](T-P12-launcher.md).

- **Search templates…**: shows only templates whose name, description, details or included features contain the
  text.
- **Filter chips**: All · 8, Action, Adventure, RPG, Puzzle, Story and Racing. The chosen chip is highlighted.
- **Template cards**: Platformer, Top-down Adventure, Turn-based RPG, Shoot 'em up, Puzzle, Visual Novel, Racing
  (Mode 7) and Beat 'em up, three to a row. Click a card to show it in the details panel. Double-click it to open New
  Project with that template chosen.
- **Details panel** (right side): the template name, a large preview, a short description, an **Includes** list (for
  example "Player controller with jump and coyote time") and a line with the video mode, background layers, actors
  and scripts, such as "Mode 0 · 3 BG layers · 9 actors · 4 scripts".
- **Use this template**: opens New Project with this template chosen.
