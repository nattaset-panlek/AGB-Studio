# Command Palette

Figma: T-O07 · Popover

> กด Ctrl+K เพื่อค้นหาคำสั่ง ไฟล์ ฉาก หรือ asset แล้วกระโดดไปได้ทันที

Press Ctrl+K to search for a command, file, scene or asset and jump straight to it.

## Opens from

- Edit › Command Palette… (Ctrl+K)
- Edit › Find in Project… (Ctrl+Shift+F)
- Ctrl+K anywhere in AGB Studio

## What is on it

- **Search box**: type what you are looking for. Results update as you type. Esc closes the palette.
- **Commands**: menu commands that match, with their keyboard shortcut on the right (for example Play, F5).
- **Files**: files of the open project that match, with their folder on the right (Sprites, Scripts, Tilesets ...).
  Files you opened from the palette before come first.
- **Matching**: names that start with your text rank first, then word starts, then text anywhere, then letters in
  order, so "pla" also finds Palette Manager. Up to 3 commands and 3 files are shown.
- **Commands only**: start the search with ">" to list commands only (up to 8).
- **Keys**: Up / Down move the highlight, Enter runs the command or opens the file, Esc closes. The hints at the
  bottom show these keys.
- **Opening a file**: each file opens in its own editor: sprites in the Sprite Editor, maps and tilesets in the Tilemap
  Editor, scripts in the Script Editor, fonts in the Font Manager, data tables in the Database, dialogue in the Dialogue
  Editor, logic graphs in the Logic Graph, and sounds and music in Audio. Other files, scenes included, bring up the
  Scene Editor.

Differs from Figma: the caption says you can jump to a scene; picking a `.scene` file shows the Scene Editor but keeps
the scene that is open. Use the Scene Switcher to change scene.
