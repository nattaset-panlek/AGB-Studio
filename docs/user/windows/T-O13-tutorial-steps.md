# Tutorial Steps

Figma: T-O13 · Popover

> แผงบทเรียนที่ลอยข้าง editor ขณะทำตาม: บอกขั้นตอน มีภาพประกอบ ติ๊กเองอัตโนมัติเมื่อทำเสร็จ และย้อน/ถัดไปได้

A tutorial panel that floats beside AGB Studio while you follow it: it tells you each step, shows a picture, ticks
itself when you finish a task, and lets you go back or forward.

## Opens from

- Launcher › Learn › Tutorial Start / Continue (and Review for a finished tutorial)
- The Learn list on the Launcher home (Projects tab)

## What is on it

The panel sits at the lower right and does not block AGB Studio: you can select, edit and play while it is open. It
stays open when the page changes, for example when the project opens or Play Mode starts.

- **Header**: the tutorial name and where you are, for example "Your first platformer · 3 of 8". The X closes the
  panel; your progress is kept and Continue picks up from the same step.
- **Progress bar**: how many of the tutorial's tasks are done.
- **Step title and text**: what this step is about and what to do.
- **Picture**: shown for steps that have one.
- **Task check boxes**: the tasks of this step, such as "Select Player in the Hierarchy" or "Set Jump force to 3.5".
  A box ticks itself when you do the task in AGB Studio: run a command, open a window, select an item, set a value in
  the Inspector, or press a button in Play Mode. You can also tick or untick a box yourself.
- **Back**: goes to the previous step. It is greyed out on step 1.
- **Skip**: marks every task of this step as done and moves to the next step.
- **Next step**: moves to the next step. On the last step it finishes the tutorial and closes the panel; the Learn
  tab then shows the tutorial as Done.
