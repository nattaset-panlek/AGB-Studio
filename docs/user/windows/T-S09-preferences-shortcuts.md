# Preferences · Shortcuts

Figma: T-S09 · Dialog

> แท็บ Shortcuts: แก้ปุ่มลัดได้ทีละคำสั่ง เตือนเมื่อปุ่มชนกับคำสั่งอื่น และกลับเป็นค่าเริ่มต้นได้

The Shortcuts tab: change the shortcut of one command at a time, see a warning when keys clash with another command,
and go back to the defaults.

## Opens from

- File › Preferences… (Ctrl+,), then the Shortcuts tab in the side bar

## What is on it

- **Search box** ("Search commands or press a key…"): type part of a command name to find it among all commands. Or
  press a key combination with Ctrl or Alt, or an F key, to find the command that uses it. Ctrl+A, C, V, X, Z and Y
  still work as normal in the box.
- **Command list**: with an empty search it shows the common commands: Command palette, Save, Play, Build ROM, Toggle
  grid, Paint tiles and Select tool.
- **Keys**: the current shortcut, shown as keys. A yellow chip "conflicts with …" appears when another command uses
  the same keys.
- **Pencil button**: opens Record Shortcut for that command. When you press Replace there, the new keys are set and
  taken away from any command that used them.
- **Reset to defaults**: puts every shortcut back to how AGB Studio ships.
- **Footer**: Cancel (or Esc) drops every shortcut change; Save applies them at once.
