# Launcher · Learn

Figma: T-P21 · Page

No caption in Figma.

The Learn tab of the Launcher: step-by-step tutorials with your progress, sample projects to open, and links to the
documentation.

## Opens from

- Launcher › Learn tab

## What is on it

The top bar (Open…, New Project) and the sidebar (Projects, Templates, Learn, Settings) are the same as on the
[Launcher](T-P12-launcher.md).

- **Tutorials**: one row per tutorial: Your first platformer, Scripting in C# for GBA, Making fonts with Thai,
  Palettes & VRAM, and Sound & music. Each row shows a short subtitle, your progress and a button that opens the
  Tutorial Steps panel. Progress is saved for you and kept between sessions.
  - Not started: the time it takes (for example "15 min") and **Start**.
  - Started: "40% · in progress" with a bar and **Continue**.
  - Finished: "Done" with a full green bar and **Review**, which starts the tutorial again from step 1.
- **Sample projects**: Sky Hopper demo (platformer), Cave Quest (top-down RPG), Snow Run (racing) and Dusk Story
  (visual novel). Click a card to open the sample. The first time, AGB Studio copies it into your projects folder, so
  you can change it freely.
- **Documentation** (right side):
  - **Scripting API** opens the Scripting API page.
  - **GBA hardware guide** opens the guide installed with AGB Studio, or says it is not installed.
  - **Keyboard shortcuts** opens the Keyboard Shortcuts dialog.
- **Community**: **Release notes** opens the release notes as a text file; **Report a bug** runs Help › Report a
  Bug….
