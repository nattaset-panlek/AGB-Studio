# Grid & Snap

Figma: T-O03 · Popover

> ตั้งขนาดตาราง การ snap และสิ่งที่แสดงซ้อนบน viewport

Set the grid size, snapping, and what is drawn on top of the scene view.

## Opens from

- The grid chip "Grid 16" at the bottom right of the scene view (#19)

## What is on it

- **Title bar**: "Grid & Snap", with a close button.
- **Grid size**: 8, 16 or 32 pixels. The grid chip shows the size you pick.
- **Show grid**: draws the grid over the scene. The grid button in the toolbar (G) turns it on and off too.
- **Snap to grid**: when on, dragged actors line up with the grid, and the arrow keys move the selected actor one grid
  step. When off, the arrow keys move it one pixel.
- **Tile collision**: shows the collision of the tiles in the scene view.
- **Camera bounds**: shows the camera limits in the scene view.
- **Grid colour**: white, blue or red. The chosen colour has a ring around it.
- Changes apply at once; there is no Save button.
