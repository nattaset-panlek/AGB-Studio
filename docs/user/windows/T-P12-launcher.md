# Launcher

Figma: T-P12 · Page

> หน้าแรกเมื่อเปิดโปรแกรม: เปิดโปรเจกต์ล่าสุด เริ่มโปรเจกต์ใหม่จาก template ตามแนวเกม และดูบทเรียน

The first page you see when AGB Studio starts: open a recent project, start a new one from a genre template, or
look at the tutorials.

## Opens from

- App start (when no project is open)
- File › Open Project… (Ctrl+O)
- Help › Getting Started
- Projects in the Launcher sidebar

## What is on it

The Launcher fills the whole window. The menu bar is hidden while it is shown.

- **Top bar**: shows the AGB Studio version and whether devkitARM was found, for example "v0.1 · devkitARM 16.1
  found". **Open…** picks a project folder; the folder must hold a `.agbproj` file, or a message says none was found.
  **New Project** opens the New Project dialog.
- **Sidebar**: the AGB Studio name and version, then **Projects**, **Templates** and **Learn** (the three Launcher
  tabs) and **Settings**, which opens Preferences.
- **Recent projects**: one card per recent project, with a preview, the name and when it was last opened. Point at a
  card to see its folder. Click a card to select it; double-click it, or press Enter, to open it.
- **Rename**: press F2 on a selected card, type the new name and press Enter (Esc keeps the old name). This changes
  the name inside the project file; the folder keeps its name.
- **Right-click a card**: opens the project menu with Open, Show in Explorer, Duplicate, Rename, Remove from list and
  Delete project…. Delete project… asks first, lists what is in the project, then moves the folder to the Recycle Bin.
- **Search projects…**: shows only the projects whose name contains the text.
- **Start from a template**: the first three templates (Platformer, Top-down Adventure, Turn-based RPG). Click one to
  open New Project with that template chosen. **All templates** opens the Templates tab.
- **Learn** (right side): the first four tutorials. Click one to start it in the Tutorial Steps panel.
- **What's new**: the highlights of this version's release notes.
