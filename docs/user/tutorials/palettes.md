# Palettes & VRAM

why 16 colours, and how to fit more · 10 min · 2 steps

The GBA draws tiles and sprites with 16-colour palettes and has a fixed amount of video memory (VRAM). This tutorial
shows where AGB Studio shows both.

## 1. Open the Palette Manager

Each sprite and tile uses one 16-colour palette; the GBA has 16 of them for each layer type.

- [ ] Open the Palette Manager (Tools › Palette Manager)

## 2. Check VRAM

The budget shows how much video memory the scene uses.

- [ ] Open Budget Details (click the GBA Budget block at the bottom of the Inspector)
- [ ] Open the Build Report

Either task finishes the step.
