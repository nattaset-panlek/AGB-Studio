## Links whose app control is not the Figma node

- #48, #73, #75, #76: Figma links the Scene menu title of the title bar back to the Scene Editor; in AGB Studio that title opens the Scene menu (T-M04, as Editor Map board 2 draws it), and the Scene document tab leads back to the Scene Editor.
- #55: Figma links the Build menu title of the Scene Editor straight to Build ROM (T-D06); in AGB Studio that title opens
  the Build menu (T-M05, as Editor Map board 2 draws it), and Build ROM is its first item. The test clicks Build › Build ROM.

Triggers: every link is ON_CLICK. Asset Card links are double-clicked in the app, as Editor Map #24 says ("Asset (double-click)"); Figma prototypes have no double-click trigger.

Dialog Footer › Cancel of About and Keyboard Shortcuts: both show one footer button, Close, in Figma and in the app (the footer's Cancel instance, where Figma put the link, is hidden in the frame); the test clicks Close.
