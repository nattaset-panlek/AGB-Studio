# ลำดับการตรวจและ re-check AGB Studio (คู่มือคนทดสอบ)

ใช้คู่มือนี้ทุกครั้งที่มีของใหม่ให้ลอง ทำตามลำดับ เพราะขั้นหลังพึ่งขั้นก่อน
จดผลทุกข้อเป็น ผ่าน / ไม่ผ่าน + ภาพหน้าจอ ลงไฟล์ `docs/evidence/qa-<วันที่>.md` (หรือส่งในแชตก็ได้)

## 0. เตรียม
1. ดับเบิลคลิก `build-and-run.cmd` ที่ราก repo: build แบบ Release แล้วเปิดโปรแกรมให้เลย
   - ถ้าจะลองแบบผู้ใช้จริง (zip): รัน `build-and-run.cmd package` แล้วใช้ `build\package\AGB-Studio-1.0.0-win-x64.zip`
2. ถ้าโปรแกรม crash: เปิดโฟลเดอร์ crash จากข้อความแจ้ง แล้วส่งไฟล์ `crash-*.log` มาด้วยทุกครั้ง

## 1. เปิดครั้งแรกและโปรเจกต์ (5 นาที)
1. หน้า Launcher เปิดขึ้นมา ไม่มี error
2. New Project: ลองทุก template ทีละตัว ชื่อไทยและอังกฤษ
3. เปิดโปรเจกต์ที่สร้าง: Hierarchy มี object ที่มี component ให้เห็น, Inspector บอกว่าแต่ละ component ทำอะไร
4. ปิดแล้วเปิดใหม่: Recent projects ขึ้น, เปิดกลับมาสถานะเดิม

## 2. การนำทาง (สำคัญที่สุด, 10 นาที)
ทำทุกข้อแล้วดูว่า panel/ปุ่ม/การเลือก ไม่หาย ไม่ค้าง:
1. กดไปทุก page และทุก tab ทีละอัน แล้วกลับมาหน้าเดิม
2. สลับไปมาแบบสุ่ม 2 รอบ (เช่น Scene -> Scripting -> Debug -> Assets -> Scene)
3. ทุกหน้าที่เข้าไปได้ ต้องออกได้ (ปุ่ม back/close/tab อื่น)
4. เปิด tool/panel แล้วสลับ tab: panel ที่ควรอยู่ต้องอยู่, ที่ไม่ควรอยู่ต้องหาย อย่างสม่ำเสมอ

## 3. Play และ Debug (10 นาที)
1. กด Play: เกมรัน, ตัวนับ frame วิ่ง, ปุ่ม Play/Pause/Step ไม่ขยับ
2. Pause แล้ว Frame Step ทีละ frame
3. ระหว่าง Play ไปหน้าอื่น แล้วกลับมา: ไม่ค้างอยู่ในหน้า Play, เกมหยุดหรือรันต่อแบบที่บอกไว้
4. Stop แล้วแก้ scene แล้ว Play ใหม่: เห็นสิ่งที่แก้

## 4. Build และ Export (5 นาที)
1. Build: สำเร็จ, Build Report เปิดได้
2. Export .gba สองครั้งติดกันไปที่โฟลเดอร์เดิม: ไม่มี error ว่าไฟล์ถูกใช้อยู่
3. เปิด .gba ที่ได้ใน emulator (เช่น mGBA หรือ VBA-M): เกมรันเหมือนตอน Play

## 5. ฟีเจอร์ทีละตัว (ตามเวลาที่มี)
ต่อแต่ละหน้า: ทำงานหลักของหน้านั้น 1 อย่าง, Undo/Redo, บันทึก, ปิดเปิดโปรเจกต์แล้วของยังอยู่
- Scene / Tilemap / Tileset (Primary tileset)
- Sprites / Animation
- Scripting (Behaviour, Node graph) และออกจากหน้าได้
- Audio (เพลง, เสียง)
- Text / Localization / Dialogue (ภาษาไทย: สระบน-ล่าง วรรณยุกต์อยู่ถูกที่)
- Database, Preferences, Keyboard Shortcuts

## 6. re-check หลังแก้บั๊ก
1. ทำซ้ำเฉพาะข้อที่เคย "ไม่ผ่าน" ก่อน
2. แล้วทำหมวด 2 และ 3 ซ้ำทั้งหมด (บั๊กการนำทางมักกลับมา)
3. ถ้าผ่านหมด: แจ้ง "อนุมัติ release" เพื่อปิด P16.X1
